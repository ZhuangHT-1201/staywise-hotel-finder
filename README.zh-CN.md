# 住得值 StayWise

[English](README.md) | **简体中文**

住得值是一个中英双语的酒店比价与选址推荐项目。它支持搜索具体校区、公司、车站和商圈，也支持输入两个地点，在约会中点附近优先寻找低价酒店。

![住得值中文界面](docs/screenshots/chinese-home-fold.png)

## 核心功能

- 具体地点搜索，例如“北京航空航天大学沙河校区”
- 双点约会模式，兼顾最低价与两人的通勤位置
- 美团、携程、飞猪、Booking 四平台报价对比
- 最划算、综合优选、住得更好三套透明排序模型
- 酒店图片预览、评分、早餐、免费取消与全程总价
- 预算、评分、收藏等筛选
- 最多三家酒店横向对比
- 14 天价格趋势与本地价格提醒
- 一键中英切换，适配桌面和手机

![双点约会搜索](docs/screenshots/english-date-midpoint.png)

## 立即运行

Windows 用户直接双击 [`启动住得值.cmd`](启动住得值.cmd)。启动器会自动构建、启动本地服务并打开浏览器。

也可以在终端运行：

```bash
npm install
npm start
```

开发模式：

```bash
npm run dev
```

## 搜索示例

1. 选择“地点找房”。
2. 输入“北航沙河”，从下拉建议中选择“北京航空航天大学沙河校区”。
3. 设置日期、人数和房间数。
4. 保持“最划算”偏好，价格会作为第一排序因素。
5. 如需双人约会推荐，切换到“双点约会”并填写两个人的位置。

## 数据说明

当前酒店、库存、报价、评分和趋势均为演示数据，不是实时价格，也不构成预订承诺。要上线真实比价和下单，需要接入获得授权的酒店分销、联盟或直连 API。
